# Рилс от персонажа

Кнопка «🎭 Рилс от персонажа» (команда `/talk [тема]`) в боте запускает `.github/workflows/talk.yml`.
Человека в кадре нет: рассказывают герои игры, по очереди ведущий и гость (перепалка, перебивки).

- Ведущий по кругу: Мастер Гром, Князь Диван, Борис Петрович, Купец Фёдор; тон по кругу: смешной, мотивирующий, с советами
  (4 × 3 — все сочетания за 12 рилсов). Гость — Князь Диван, а у самого Князя — Гром.
- `generate.mjs` — сценарий от Claude: реплики с `who`, кадром `layout` (vlog — крупно, как блогер на фронталку, фоном размытая игра;
  corner — игра на весь экран, персонаж в углу), жестом и клипом из `../reels/catalog.json`.
- `synth.py` — голос: мужской edge-tts со своим сдвигом тона и темпа у каждого персонажа; тайминги и громкость по кадрам → `timing.json`.
- `render.mjs` + `scene.html/scene.js` — 3D-модель KayKit в headless Chrome (WebGL на SwiftShader), рот открывается по громкости,
  15 кадров в секунду с прозрачным фоном; плюс титры, хук, плашки имён.
- `build.py` — монтаж ffmpeg, музыка из `../reels/music`, вторая версия только с голосом.
- `send.mjs` — файлы админу в Telegram.

Локально: `cd out && node ../promo/talk/generate.mjs 0 && python3 ../promo/talk/synth.py && node ../promo/talk/render.mjs && python3 ../promo/talk/build.py`
(нужны `CLAUDE_CODE_OAUTH_TOKEN`, edge-tts, ffmpeg, playwright).
