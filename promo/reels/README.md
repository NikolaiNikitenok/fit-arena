# Рилсы для Instagram по кнопке

Админ жмёт в боте «🎬 Новый рилс» (или `/reel тема`) → `server/reels.ts` запускает `.github/workflows/reel.yml` → готовый файл 1080×1920 и подпись с хэштегами приходят админу в Telegram.

Шаги в workflow (каждый — отдельный скрипт, запускается из рабочей папки):
1. `generate.mjs <номер> [тема]` — Claude (подписка `CLAUDE_CODE_OAUTH_TOKEN` или `ANTHROPIC_API_KEY`) пишет `script.json`: хук, 5–7 коротких реплик (14–18 с), по 1–2 клипа на реплику из `catalog.json`, призыв на финальном экране, подпись и 3–5 хэштегов. Формула хука (POV, вызов, спор, пари с другом…) меняется по номеру рилса; первый клип — один из помеченных `"hook": true`.
2. `synth.py` — озвучка нейроголосом Microsoft (edge-tts, без ключа), `vo/N.wav`. В озвучке название всегда «Никитёнок» через ё.
3. `render.mjs` — крупный хук, субтитры по словам (текущее слово подсвечено) и плашка призыва (Playwright, шрифт Nunito из `fonts/`).
4. `build.py` — монтаж из `footage.mp4`: хук звучит с первого кадра поверх самого яркого клипа, склейки с наездом и медленным зумом, вспышка и «вжух» на смене фраз, музыка сразу на полную под голосом, финальный экран без затемнения (рилс зацикливается). Рядом `reel-voice.mp4` (только голос) и `cover.jpg` (обложка с хуком).
5. `send.mjs <chat_id>` — отправка двух роликов без пережатия (с музыкой и без), обложки и подписи.

Музыка: `music/<id>.m4a`, описания настроений в `music/library.json` — по ним Claude выбирает трек. Свои 8 треков синтезируются `music/synth.js` (`node music/make.mjs [id…]`). Чужой трек можно добавить так же: файл `music/<id>.m4a` (34+ с, без авторских прав) и строка в `library.json`.

Видеоряд: `footage.mp4` — 19 сцен текущей игры на весь экран 1080×1920 (бой с боссом, башня, дуэль, набег, деревня, подземелье, рейд клана, карта, главная, загрузка, питомец, лавка, пропуск, достижения, программы, праздник, финальный экран), записаны покадрово в headless Chromium с синтетическим спортсменом перед камерой. Скрипты записи и сборки — в файлах проекта `promo/source/v3`. Новая сцена: добавить кусок в `footage.mp4` и описать его в `catalog.json` (`from`/`to` в секундах, что видно, `"hook": true` для ярких кадров, которые годятся в первую секунду). Необязательно: `fx` — моменты внутри клипа `[секунда от начала клипа, "hit" | "big", "текст наклейки"]` (на них тряска, на `big` ещё глитч и наклейка, а монтаж берёт кусок клипа вокруг первого `big`), `zoom` — `[во сколько раз, x, y]` для мелкого плана.

Склейки попадают в бит: темп каждого трека в `music/tempo.json` (свой трек без темпа просто режется без привязки к биту).
Секреты: `GH_ACTIONS_TOKEN` (fine-grained, только этот репозиторий, Actions: Read and write) для кнопки; `BOT_TOKEN`, `CLAUDE_CODE_OAUTH_TOKEN` уже есть.
