# NIKITENOK Arena, ID и «Свобода»

Репозиторий включает три продукта:

| Продукт | Код | Рабочий адрес |
|---|---|---|
| Arena: фитнес, приключение, дуэли, кланы, деревня и зал | `src/`, `shared/`, `server/` | https://arena.nikitenok.ru |
| NIKITENOK ID: единый аккаунт и OIDC | `id/server/` | https://id.nikitenok.ru |
| «Свобода»: привычки, SOS, занятия и сад | `habit/`, `server/habit.ts`, `server/habitIndex.ts` | https://habit.nikitenok.ru |

Код Family, серверной панели и Sheriff хранится отдельно: https://github.com/NikolaiNikitenok/nikitenok-services.

## Проверки и сборка

Node.js 22.13+:

```sh
npm ci
npm test
npm run build
npm run build:server
npm run build:id
```

Серверная сборка создаёт `dist-server/server.cjs` и независимый `dist-server/habit.cjs`.
Имена файлов компонентов различаются от имён модулей логики, поэтому сборка работает также в Windows.
Два теста с исполняемыми shell-фикстурами выполняются в Linux CI и пропускаются на Windows.

## Рабочие процессы

- `arena-server.service`: матчи, игровые API и боты, только 127.0.0.1:8787; данные `/opt/arena-server/data`.
- `nikitenok-habit.service`: API `/api/habit/*`, только 127.0.0.1:8790; данные `/opt/nikitenok-habit/data`.
- `nikitenok-id.service`: OIDC, только 127.0.0.1:8096; SQLite и ключи `/opt/nikitenok-id/data`.
- Caddy раздаёт frontend и направляет API привычек в отдельный сервис. Адрес API «Свободы» совместим с прежним.
- `nikitenok-habit-deploy.path` перезапускает сервис «Свободы» после изменения его bundle при деплое.

Новый сервер сначала настраивают по `deploy/` и systemd-конфигурациям из `nikitenok-services/deploy`.
GitHub Deploy собирает и выкладывает код при push в main. Рабочие конфигурации, токены и базы в Git не входят.

## Аккаунты и сохранения

В Telegram Arena проверяет подпись initData. В браузере доступны NIKITENOK ID, Telegram и Яндекс.
Прогресс игры хранится локально и синхронизируется с сервером; future timestamps ограничены серверным временем.
«Свобода» работает локально/offline, а после входа синхронизирует прогресс с отдельным backend.
Family передаёт тренировки и сводки привычек через подписанные интеграции.

Telegram-вход ID и привязка требуют одноразового состояния и cookie того же браузера; для привязки
проверяется исходная ID-сессия. После «выйти на всех устройствах» или удаления ID старые ID-сессии
Arena, «Свободы» и Family отзываются через версию авторизации. Обновление в приложениях — до 30 секунд;
при длительной недоступности ID проверка закрывается. Сессии собственных способов входа независимы.
При миграции формата сессий «Свободы» потребуется один повторный вход; сохранённый прогресс остаётся.
Удаление ID удаляет его идентичности и отзывает вход, но данные приложений удаляются в самих приложениях.

## Как считаются повторы

`src/repCounter.ts` берёт угол в ключевом суставе со стороны, которую камера видит лучше, и считает повтор при переходе «верх → низ → верх».

| Упражнение | Угол | Низ | Верх | Камера |
| --- | --- | --- | --- | --- |
| Отжимания | плечо-локоть-запястье | < 90° | > 155° | сбоку, на полу; корпус должен быть прямым |
| Приседания | таз-колено-лодыжка | < 100° | > 160° | сбоку или вполоборота |
| Пресс | плечо-таз-колено | < 70° | > 110° | сбоку, на полу |

Кроме угла, в каждом кадре проверяется положение тела: для отжиманий упор лёжа и ладони на полу, для приседаний стойка, для пресса таз и стопы на полу; стопы должны быть в кадре. Повторы быстрее 400 мс не засчитываются. Модель (`public/models/pose_landmarker_lite.task`) и WASM раздаются со своего хостинга, без внешних CDN.

## Карта «Битвы городов»

Контуры России и соседей, сетка и 260 городов с координатами собраны из [Natural Earth](https://www.naturalearthdata.com/) (общественное достояние), границы — в варианте «с точки зрения России». Готовые файлы — `src/city/mapShapes.ts` и `shared/russiaCities.ts`; пересобрать их можно так: скачать `ne_10m_admin_0_countries_rus.geojson` и `ne_10m_populated_places.geojson` из [natural-earth-vector](https://github.com/nvkelso/natural-earth-vector/tree/master/geojson) в одну папку и запустить `node scripts/build-map.mjs <папка>`. Разговорные названия городов («Питер», «екб») — в `shared/cityNames.ts`.

## 3D-модели

Персонажи, постройки, космическая база и город — наборы [KayKit](https://kaylousberg.itch.io/) от Kay Lousberg (лицензия CC0). Исходники лежат в ветке `assets-kaykit`; `node scripts/build-assets.mjs <папка kaykit>` собирает из них сжатые файлы в `public/models/chars` и `public/models/lib`.
