# Fit Arena

Telegram Mini App для соревнований в отжиманиях, приседаниях и прессе. Камера телефона считает повторы прямо в браузере через MediaPipe Pose, видео никуда не отправляется.

Сейчас это первый прототип: выбор упражнения, раунд на 60 секунд, подсчёт повторов с проверкой амплитуды и подсказками. Дальше по плану 3D-арена с дуэлями, бот, профили и рейтинги.

## Запуск

```bash
npm install
npm run dev     # http://localhost:5173, в сети доступен по IP компьютера
npm test        # тесты счётчика повторов
npm run build   # сборка в dist/
```

Камера работает только по HTTPS (или на localhost). Чтобы открыть прототип в Telegram, задеплойте `dist/` на любой HTTPS-хостинг (Vercel, Cloudflare Pages) или пробросьте dev-сервер через туннель, затем укажите адрес у бота через @BotFather → Bot Settings → Menu Button.

## Как считаются повторы

`src/repCounter.ts` берёт угол в ключевом суставе со стороны, которую камера видит лучше, и считает повтор при переходе «верх → низ → верх».

| Упражнение | Угол | Низ | Верх | Камера |
| --- | --- | --- | --- | --- |
| Отжимания | плечо-локоть-запястье | < 90° | > 155° | сбоку, на полу; корпус должен быть прямым |
| Приседания | таз-колено-лодыжка | < 100° | > 160° | сбоку или вполоборота |
| Пресс | плечо-таз-колено | < 70° | > 110° | сбоку, на полу |

Повторы быстрее 400 мс не засчитываются. Модель (`public/models/pose_landmarker_lite.task`) и WASM раздаются со своего хостинга, без внешних CDN.
