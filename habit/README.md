# Свобода — отказ от вредных привычек

Отдельное веб-приложение (не часть игры) на https://habit.nikitenok.ru.
Чистый HTML/CSS/JS без сборки, данные хранятся в localStorage устройства, работает без сети (sw.js) и ставится на главный экран (PWA).

- Знакомство (`onboarding` в app.js): привычка, когда бросаю (сейчас / уже / назначить день), причины, триггеры → личный план.
- Главная: отметка настроения и обещание на день, фраза часа, кнопка SOS, таймеры, копилка на цель, последняя награда.
- SOS: сила тяги 1–10 и триггер → советы и 3 занятия под триггер (store.suggestActivities) → после занятия сила тяги снова → победа или срыв.
- Срыв: «оступился» (таймер идёт) или «начать заново» (лучшая серия и деньги сохраняются), причина и совет.
- Прогресс: график тяги за 2 недели, часы пик, триггеры, календарь настроения, 16 наград.
- Мотивация: фразы по времени суток (phrases.js), причины, письмо себе, контакт для звонка, уведомления, копия данных.
- Занятия (activities.js): волна, прогулка, 2 дыхания, 5-4-3-2-1, пузыри, пары, реакция, счёт в уме, зарядка, быстрое дело, причины, письмо.
- Карточка «Поделиться» 1080×1350 (share.js).

Локально: `cd habit && python3 -m http.server`.
Сервер: один раз `sudo bash deploy/setup-habit.sh habit` (Caddy-блок + /var/www/habit), дальше автодеплой при пуше в main.
