# Срочное исправление готовности отжиманий — 2026-11-05

Пользователь сообщил production-блокировку кнопки «Начать» и зеленого контура, приняв упор лёжа в плане тренировок. Воспроизведены причины на синтетических landmarks; точная причина конкретного телефона без его потока не доказана.

1. Выбор стороны только по сумме уверенности трех суставов выбирал сторону со скрытым тазом либо кистью, хотя другая сторона целиком годилась. Новый exerciseReadiness проверяет стороны целиком независимо, с прежними порогами/положением, aspect и разрешенными поворотами; точки разных сторон не смешиваются. RepCounter предпочитает целиком пригодную сторону тем же требованиям, иначе калибровка и счет оставались бы заблокированы после открытия кнопки.
2. Любой один ошибочный кадр обнулял все1.5с готовности. При обнаруженном человеке теперь допускается ограниченный сбой до200мс; плохой кадр не открывает кнопку и не продвигает подготовку/отсчет. На возвращении время сбоя исключается. Длительная потеря, отсутствие человека или зависший поток требуют новую готовность. После ACTIVE исходный тренировочный дедлайн не меняется.
3. Контур рисуется после текущего расчета готовности, синхронно с доступностью кнопки. Новый helper заменяет сбрасываемый каждый кадр временный RepCounter; лишнее состояние probe удалено.

Пороги амплитуды, минимум уверенности суставов, награды/экономика/рейтинги, модели/3D и пользовательские сохранения не менялись. Не добавлен обход readiness или ручной зачет упражнения. Кнопка подтверждения сохранена.

Независимый QA:119 PASS в7 целевых файлах, tsc PASS. Добавлены helper-тесты обоих дефектов стороны, отсутствия человека/суставов, неправильной стойки и необязательных ног, aspect/rotation; FSM тесты одиночного33мс сбоя, потери>200мс, восстановления после500мс; hook тест pushup→go→ACTIVE с шумом без начислений подготовки;2 счетных теста по3 медленных отжимания и реальный Calibrator.result.
